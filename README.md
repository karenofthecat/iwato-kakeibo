# iwato家計簿 v0.7.20

個人用・ブラウザ内保存型の家計簿アプリ。

サイト: https://karenofthecat.github.io/iwato-kakeibo/

## データの保存先

- 家計の入力データは利用者のブラウザの localStorage に保存されます。
- GitHub Pages は静的なアプリを配信します。現在の実装では家計データを GitHub に自動送信しません。
- Safariのサイトデータ削除や端末変更などでデータを失う場合があります。設定・バックアップのJSONを安全な非公開の場所に保管してください。
- バックアップJSONには支出明細、口座残高などが入っています。公開リポジトリに投稿しないでください。

## v0.7.20 セキュリティ・プライバシー修正

- 公開プログラムに含まれていた個人の家計データ・初期値・旧復旧用データを取り除きました。
- 復旧処理による自動的な過去の明細投入を停止。端末に保存済みの記録・スナップショット・給与実績・固定費を引き続き読み込みます。
- 表示するメモ、支払名、履歴ラベル等のHTML特殊文字をエスケープし、イベント操作に使用するIDを限定。
- 固定値を持つ過去の復旧機能は取り下げ、バックアップJSONからの復元を使用します。
- Safariのキャッシュ名を更新。

## 注意事項

このリポジトリは公開されています。過去のGitコミットに存在したデータは、現在のコードから削除してもコミット履歴に残ります。履歴の削除・リポジトリ再作成はデータ喪失や公開停止の危険があるため、別途安全なバックアップと移行計画のもとで行ってください。

このアプリはブラウザ側のデータを暗号化していません。共有端末や信頼できない拡張機能のある環境では使わないでください。
