# iwato家計簿 v0.7.2

## データ消失対策
- v0.7.1で旧分割データを保存データから削除していた不具合を修正
- 今後の移行では既存取引・分割・代理・月次履歴を削除しない
- 固定費マスターと重複する旧分割は、保存したまま表示・予測だけ除外
- 現在データ、旧v0.5データ、復元ポイントを比較する「消えたデータを自動救出」を追加
- 起動時にも復元ポイントの方が明らかに情報量が多い場合は自動救出
- 救出前、旧データ再取込前には復元ポイントを自動保存

## 操作
出力タブ → 消えたデータを自動救出

実績・予測、固定費分類、代理個別管理、カード編集・返金、月締めロックは維持しています。
