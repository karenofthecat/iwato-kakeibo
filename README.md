## 0.7.13
- 2026年10月以降の夜職給与見込みを、安全側の105,000円に変更。保存済みの古い見込み額も10〜12月は105,000円へ補正。

## 0.7.12
- 画面上のバージョン表記を v0.7.12 に更新。
- 8月を締める前に9/1に入力した8月実績（利息251円、夜職給与107,211円、昼職給与85,598円）を8月へ帰属するよう補正。
- 8月通帳出金172,784円を実績として反映し、口座残高119,145円へ着地。
- 分析では実績給与がある月は見込み給与より実績を優先。
- 暦が翌月へ進んでも家計簿の表示月が前月のままなら、新規入力は表示中の月末日へ記録するよう修正。月締め前の追加入力が翌月扱いになる問題を防止。
- Service Worker のキャッシュ名を更新し、旧版表示が残りにくいよう修正。


## 0.7.14
- 口座払いの通常支出を資金推移へ反映。
- 月締め時は分析画面と同じ資金推移を確定保存。
- 確定月は実績給与・その他口座入金を保持し、旧見込み額へ戻らないよう修正。


## v0.7.15
- 9月の通帳CSV実績（口座引落112,139円）を資金推移へ反映。
- 口座の現在残高を月初残高＋入金－口座支出－通帳引落から再計算し、削除→再入力で残高が二重に減る問題を修正。
- ホーム・分析・月締めで同じ口座収支を使用。9月は190,168円への着地を基準にします。

## v0.7.16
- 分析に月別の夜職・昼職給与実績入力欄を追加。実績入力は資金推移の暫定額を置換し、二重加算しない。
- 入金履歴がある場合は自動的に実績を優先。手入力実績を設定した月は手入力を最優先し、解除すると入金履歴または暫定額に戻る。
- 給与実績欄は分析専用で、口座残高の二重操作を避けるため入金記録は作成しない。
- 固定費タブで終了済み支払いを分離。「一覧から消す」で履歴と過去のカード請求計算を保持しつつ整理し、再表示可能。
- 月締め時に未確定の給与を実績ゼロと誤記録しないよう修正。
- Service Worker のキャッシュを v0.7.16 に更新。

## v0.7.17
- 「分析」から保存した給与実績を、現在月のホーム口座残高へも反映するよう改善。
- 同月の「夜職給与」「昼職給与」入金履歴がある場合は、給与実績の金額で置き換え、二重加算を防止。
- 口座の残高補正（実残高）が給与日以降にある場合、その補正を優先して重複加算しない。夜職は25日、昼職は月末を給与日として計算。
- 過去月の給与編集で現在月口座残高が意図せず変わらないよう、当月だけに適用。
- Service Worker キャッシュを更新。
