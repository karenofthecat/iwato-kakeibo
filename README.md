# iwato家計簿 v0.7.0

## 大きな変更
- 分析を「実績」と「予測」に分離
- 実績は入力済み取引と月締めスナップショットから表示
- 予測は固定費マスター、カード請求予定、給与予定から12月まで毎回再計算
- 固定費マスターを新設
- 固定費の金額・支払元・開始月・終了月・頻度・有効状態を編集可能
- 水道、ガス、電気、ahamo、保険、Apple、Netflix、YouTube、ChatGPT、各ローン・分割、年払いを初期登録
- ごうぎんローンは2026年7月終了済みとして停止
- iPhone 15 Proは2026年9月まで
- iPad Proは2027年11月まで
- Netflixは1,590円、2026年8月開始、終了なし
- 月締め済み月をロックし、締め解除にも対応
- 代理は複数案件の個別管理・部分回収・回収履歴を維持
- カード編集・返金・削除・復元ポイントを維持
