# iwato家計簿 v0.7.3 安定移植版

## 方針
v0.6.5の実データ入りindex.htmlを土台にし、保存データを削除しない形で機能を移植しました。

## 追加・整理
- 固定費タブを追加
- 毎月固定・変動見込、分割・定期、年払い・単発、停止済みに分類
- カードタブはカード明細確認専用
- 旧分割データは削除せず固定費タブへ表示
- 代理の個別管理・部分回収を維持
- カード編集・返金・削除を維持
- 7月末完全復旧データを維持
- 予測表の固定費は固定費マスターから毎回再計算
- 復元ポイントとバックアップを維持

## 初回確認
データが空の場合は、出力タブの
「v0.6.5の7月末データを完全復旧」
を押してください。
