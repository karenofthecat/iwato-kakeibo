## 修正
- 財布・PayPay残高・口座・ポイントなど、カード以外の通常支出も月次の費目別支出へ正しく集計
- 代理支出は費目別支出から除外し、代理タブで個別管理
- 固定費マスターの項目は支払方法に関係なく「固定」へ計上
- Apple 150円、Netflix 1,590円、YouTube Premium 1,280円など楽天カード払い固定費が「固定以外」に入る不具合を修正
- 「固定以外」は通常カード利用などの変動支出だけを計上
- カードタブの請求合計は通常利用＋固定費のまま維持
- 7月末復旧データ、代理個別管理、カード編集・返金、固定費編集、復元ポイントを維持
