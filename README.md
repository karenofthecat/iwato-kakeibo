# iwato家計簿 v0.7.5

## カード請求統合
- カードタブに通常利用と固定費マスターを合成表示
- カード別合計へ固定費・分割・年払いを含める
- 通常利用と固定費を別グループで表示
- 固定費には「📌 固定費」タグを表示
- 固定費の編集ボタンから固定費タブへ移動
- データは二重保存せず、表示時だけ合成
- FellowケトルやNetflixも請求月のカード合計へ反映
- レポートのカード請求見込みも固定費込み
- 資金推移ではカード固定費をカード請求として計上し、二重計上を防止

## 維持
- 7月末復旧データ
- 固定費マスター
- 代理の個別管理・部分回収
- カード通常利用の編集・返金・削除
- 復元ポイントとバックアップ
