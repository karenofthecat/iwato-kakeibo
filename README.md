# iwato家計簿 v0.7.4

## 重複整理
- 固定費マスターと旧分割データの重複を自動判定
- Fellowケトルは固定費マスター側の分割だけを表示・予測へ反映
- Netflixは「毎月固定」だけを正本として扱い、旧分割側は表示・予測から除外
- Vitamixとefgは旧分割データとして残す
- 重複判定は名称と金額を使い、「Netflix」と「Netflix 広告なし」のような表記差にも対応
- 元の旧分割データは削除せず保持
- カード明細、費目集計、予測表でも二重計上しない
